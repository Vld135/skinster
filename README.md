## Возможности

| | Функция | Описание |
|:--:|:--------|:---------|
| 📦 | **Overview** | Просматривай инвентарь и хранилища всех аккаунтов в одном месте. Отслеживай общую стоимость предметов |
| 🔄 | **Moving** | Быстрое перемещение предметов между инвентарём и хранилищами |
| 🛒 | **In-game Shop** | Покупай предметы без входа в игру. Без лимита — более 20 предметов за раз |
| 🏰 | **Armory** | Активируй пропуски и открывай любые коллекции прямо из приложения |
| 💰 | **Steam Market** | Продавай предметы и управляй ордерами без открытия Steam |
| 🤝 | **Trade Offers** | Создавай обмены между аккаунтами. Передавай предметы на основной аккаунт в пару кликов |
| 🔐 | **Steam Guard** | Генерация кодов авторизации и подтверждение действий |
| 🌾 | **Auto Farm** | Автоматический фарм еженедельных дропов и звёзд Armory. Статистика по всем аккаунтам |
| ⚡ | **Workflows** | Автоматизация рутинных задач по расписанию |

## Features

| | Feature | Description |
|:--:|:--------|:------------|
| 📦 | **Overview** | View inventory and storages of all accounts in one place. Track total item value |
| 🔄 | **Moving** | Quick item transfer between inventory and storages |
| 🛒 | **In-game Shop** | Buy items without launching the game. No limit — 20+ items at once |
| 🏰 | **Armory** | Activate passes and open any collections directly from the app |
| 💰 | **Steam Market** | Sell items and manage orders without opening Steam |
| 🤝 | **Trade Offers** | Create trades between accounts. Transfer items to main account in a few clicks |
| 🔐 | **Steam Guard** | Authorization code generation and action confirmation |
| 🌾 | **Auto Farm** | Automatic weekly drop farming and Armory stars. Statistics for all accounts |
| ⚡ | **Workflows** | Schedule-based task automation |
