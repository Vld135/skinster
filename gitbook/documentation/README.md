# Системные требования

Данный раздел больше предназначен для людей кто будет запускать автофарм

Рекомендованные системные требования для двух потоков

* Процессор - AMD Ryzen 5600X или Intel i5-12400f
* Видеокарта - GeForce GTX 1060 6 GB
* Оперативная память - 32 GB (частота 3600)
* SSD - 75 GB свободного места
