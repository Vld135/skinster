# Changelog

## Апрель 2026

v1.11.0

{% columns %}
{% column width="41.66666666666667%" %}

{% endcolumn %}

{% column width="58.33333333333333%" %}
* 🗺 Новые карты
  * Добавлены карты Nuke и Overpass (Если заметите проблемы с маршрутами - сообщайте)


* 🎨 Граффити в дропе
  * Добавлена опция для отключения сбора граффити из еженедельного дропа

  * Ранее нормально работал только для продажи однотипных предметов. Теперь добавлена опция для автоматического запроса цены если текущий предмет отличается от предыдущего.

* 🧠 Сценарии
  * Добавлена поддержка циклов в сценариях (Пример будет добавлен в документацию позже)

* 📝 Контракты
  * Добавлена возможность создания контрактов
  * ⚠️ 🧪 Калькулятор может содержать неточности — сообщайте о багах


* 📊 Статистика
  * Добавлена возможность отправки отчета в тг прямиком со страницы статистики

v1.10.0

{% columns %}
{% column width="41.66666666666667%" %}

{% endcolumn %}

{% column width="58.33333333333333%" %}
* 📂 Очередь папок для фарма
  * Добавлена возможность создания очереди папок для автоматического фарма
  * Панель сама переключается между папками по мере завершения
  * Удобно для работы с аккаунтами разных пользователей: больше не нужно хранить всё в одной куче, можно отслеживать дроп и его стоимость отдельно по каждому


* 🧠 Сценарии — обновления
  * Возможность запуска/остановки фарма через сценарии временно удалена (будет переработана в будущем)
  * Сценарии теперь доступны начиная с подписки Account Manager


* 🛒 Новая нода: Buy on Market
  * Добавлена нода для автоматической покупки предметов с маркета
  * Поддержка направлений: CS2, Dota, Rust, TF2
  * Можно искать предметы или использовать ссылку, задавать порядок покупки (очередь), указывать максимальную цену и количество
  * Для базового сценария достаточно 3 узлов: любая trigger node -> Account Context — список аккаунтов, Buy on Market — настройка закупки
  * Можно выбрать конкретные аккаунты или использовать все


* 📄 Отчёты в PDF
  * Нода Summary Report теперь отправляет отчёты в Telegram в формате PDF (из-за ограничений длины сообщений)
  * Добавлен просмотр отчётов прямо в приложении: Workflows → History → Reports


* 🔧 Исправления и улучшения
  * Исправлено множество мелких багов и улучшена стабильность панели

## Март 2026

v1.9.0

{% columns %}
{% column width="41.66666666666667%" %}

{% endcolumn %}

{% column width="58.33333333333333%" %}
* 🌍 Улучшение SRT
  * Для каждого сервера теперь отображается его локальное время
  * Для части серверов добавлена статистика количества игроков
  * Добавлена опция auto-srt: на каждое третье перемешивание лобби происходит смена сервера — выбор оптимального сервера происходит на основе локального времени и онлайна

  * Добавлена возможность выключения компьютера после завершения всех фарм-сессий

  * Кнопка refresh разделена на два действия:

    * Проверка только банов (не требует прокси)


* 🤖 Telegram-бот
  * Добавлена возможность проверить все аккаунты на наличие банов прямо в боте
  * При запросе статистики аккаунтов возле ников теперь отображаются цветовые индикаторы — позволяют быстро определить, отфармлен уже аккаунт или ещё нет

  * Добавлена возможность запускать фарм в заданное время
  * Автоматический запуск через минуту после начала новой фарм-недели


* ⚙️ Лутер
  * Теперь пропускает аккаунты, если Steam возвращает ошибки (ранее мог зависать)


* 💱 Auto-sell
  * Исправлено некорректное определение валют для некоторых аккаунтов
